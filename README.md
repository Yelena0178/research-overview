## 说明

- **自动忽略内容**：`.gitignore` 已默认排除 LaTeX 编译临时文件（`.aux`、`.log`、`.bbl`、`.synctex.gz` 等）、Python/Jupyter 缓存与虚拟环境、超大数值输出或归档文件（如 `.h5`、`.npy`、`.npz`、`.vtk`、`.zip` 等），以及 `.env` 等密钥配置文件。
- **公开仓库安全提示**：由于本仓库为 **Public（公开）**，请勿提交包含 API Key、私钥或受限隐私数据的文件。
