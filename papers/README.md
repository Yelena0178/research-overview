# 论文与发表资料目录 (Papers)

本目录用于集中存放各篇论文的原始资料、补充文件及阅读/成果记录。

## 目录命名规范

建议每篇论文使用独立子目录，采用 `YYYY-short-topic/` 的命名格式，例如：

```text
papers/
└── 2025-example-paper/
    ├── paper.pdf
    ├── supplementary/
    ├── figures/
    └── notes.md
```

可在子目录中放入：
- 论文正文 PDF（如 `paper.pdf` 或投稿版本）
- 补充材料（`supplementary/`）或关键图表（`figures/`）
- 单篇成果说明与笔记（`notes.md`）

## 单篇笔记模板 (`notes.md`)

```markdown
# <论文标题>

- **标题**：
- **作者**：
- **发表 venue 与年份**：
- **摘要与核心贡献**：
  - 
- **关键词**：
- **相关链接**：
  - 论文链接 / DOI：
  - 代码 / 数据集：
- **BibTeX**：
  ```bibtex
  @article{key2025example,
    title   = {},
    author  = {},
    journal = {},
    year    = {}
  }
  ```
```
