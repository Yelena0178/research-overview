# AI 研究项目目录说明 (`projects/`)

本目录用于集中收纳各个独立的未发表 AI 研究项目，每个项目放在单独的子目录 `projects/<project-slug>/` 下。

## 推荐项目结构

导入本地项目时，**可保留原有代码目录结构**，建议包含以下基础内容以便统一管理：

```text
projects/<project-slug>/
├── README.md        # 项目说明、核心方法、实验结果与待办（可参考 _template/README.md）
├── src/             # 模型与实验源码（或沿用原项目目录结构）
├── configs/         # 训练与评测配置文件
├── paper/           # 论文草稿 / LaTeX 源码 / 图表（或 draft/）
└── notes/           # 实验记录、消融想法与会议讨论笔记
```

## 导入本地项目注意事项

1. **清理嵌套 `.git` 目录**：如果待导入的本地项目本身已是一个 Git 仓库，请先删除其内部的 `.git/` 文件夹再放入 `projects/`，这样所有文件会由本总览仓库直接跟踪，而不会变成无法打开的空子模块（broken submodule）。
2. **避免大文件与敏感信息**：提交前确认未包含百兆级模型权重、数据集压缩包、`.env` 或 API 密钥文件。
3. **同步更新总览表**：新增项目后，请在仓库根目录 [README.md](../README.md) 的总览表中补充对应条目。
